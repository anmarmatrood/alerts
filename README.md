# Hyper Film Landing Page

A high-converting, single-page landing page for Hyper Film - a video agency that offers unlimited video ads with a unique quarterly shoot model.

## Design Features

- **Warm & Human Aesthetic**: Inspired by plot.so with friendly, approachable design
- **Custom Color Palette**:
  - Background: #FFFCF5 (Warm Cream)
  - Text: #1A1A18 (Soft Black)
  - Accents: #FF6B4A (Sunset Orange) & #FFD23F (Warm Yellow)
- **Typography**: Fraunces (Serif) for headings, Inter (Sans-serif) for body
- **Modern Interactions**: Hover lift effects, smooth scrolling, video modal
- **Fully Responsive**: Optimized for all device sizes

## Tech Stack

- React 18
- Vite (Build tool)
- Tailwind CSS (Styling)
- Lucide React (Icons)

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Page Sections

1. **Navbar**: Sticky glassmorphism navbar with smooth scroll navigation
2. **Hero Section**: Attention-grabbing headline with video modal functionality
3. **How it Works**: Bento grid layout explaining the unique service model
4. **Pricing**: Three-tier pricing structure with highlighted best value plan
5. **FAQ**: Accordion-style frequently asked questions
6. **Footer CTA**: Strong call-to-action for strategy audit

## Customization

All colors, fonts, and content can be customized in:
- `tailwind.config.js` - Colors and design tokens
- `src/App.jsx` - Content and structure
- `index.html` - Meta tags and page title
